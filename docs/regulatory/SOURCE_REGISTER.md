## 4. Source Hierarchy & Precedence Rules

When evaluating an application, NIYAMSETU strictly follows this statutory order of precedence:

```
1. AICTE Act, 1987 (Parliament of India)
   └── Subordinate to none; defines non-negotiable Council decision powers (§10/§11).
       │
2. AICTE Addenda & Corrigenda for AY 2026–27 (Latest Gazette)
   └── Overrules earlier conflicting handbook provisions for AY 2026–27 cases.
       │
3. AICTE Approval Process Handbook (APH 2024–27 Base Text)
   └── Substantive procedural norms for Chapters I, II, VII, VIII, and Table 2.3.
       │
4. Official Public Circulars & Academic Calendars (Annual AICTE Directives)
   └── Governs statutory cutoff dates and operational deadlines.
       │
5. NIYAMSETU Engineered Safeguards (Internal Platform Controls)
   └── Clearly labeled as internal safeguards (e.g. Scope-Lock HTTP 409, 200m Geo-fence).
       Never presented as statutory clauses without explicit legislative citations.
```
