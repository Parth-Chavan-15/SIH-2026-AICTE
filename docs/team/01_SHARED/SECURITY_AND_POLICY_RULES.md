# Mandatory guardrails: identity, state, policy and evidence

1. **Auth:** no token -> 401; invalid/expired/tampered -> 401; wrong password or unknown user -> 401; never default to officer. Demo account selection must be an explicitly authenticated fictional/demo mode, not a missing-token fallback. Sanitize all auth responses.
2. **Scopes:** `actor.institutionIds` and `actor.regionIds` enforced for list, detail, update, document content, dashboards, audits, sockets and notifications. Conceal unauthorized existence appropriately. Denial must not mutate the case.
3. **Decision rights:** `policy_admin`/generic `admin` never grants final legal authority. Only synthetic explicitly delegated `demo_authority` can enter a labeled simulated decision. No automated approval, penalty or withdrawal.
4. **Transitions:** action + expectedVersion + idempotencyKey + evidenceVersionIds; no caller-controlled arbitrary target stage. Check pinned route and signed prerequisites; stale ->409; bad enum ->422; unauthorized ->403; accepted command -> exactly one committed event.
5. **Re-scrutiny:** signed initial snapshot with immutable accepted C3 and deficient D1/D2; corrections can touch D1/D2 only; unflagged item must fail server-side even if UI sends it; record an explainable denial security event without changing domain state.
6. **EVC:** only if source-pinned applicability and prior authorized review; at most one active task per generation; no EVC for a scrutiny-only case, no unreviewed task assignment.
7. **Policy:** APH 2024–27 and 2026–27 updated addendum/errata precedence; verify effective session/category/accreditation. X=360 unresolved -> POLICY_REVIEW_REQUIRED. `n divisions` must not be interpreted as seat count without a source. Do not universalize SHC/appeal/EVC.
8. **Timers:** Distinguish academic calendar cutoff, source event-relative period (including intimation/publication where specified), evidence validity and fictional operational SLA. Advance demo clock explicitly. Dedupe + generation + cancel and check current state immediately before dispatch. Never send email/SMS by default.
9. **Documents:** actual private upload under owner scope; MIME/size validation; stable object reference; version chain not overwritten; `submitted` != `verified`; review by a different authorized actor; file encryption or certified hash claims only if truly proven.
10. **Logs:** actor, time, source, case version, before/after, causal event IDs; safe CSV export against formula injection; no secrets and no fabricated IP/hash strings. Never claim WORM-compliant or court-certified absent real controls.
11. **Storage:** no silent switch between Mongo and process memory. Transaction-capable DB required for authoritative commits; startup/readiness failure explicit. Use synthetic fixtures for demos, never real institutional records.
12. **Deployment:** default no public network bind while auth insecure; restrict CORS, sessions and socket subscriptions; no real SMTP/AICTE/NIC/NSWS/banking API without authorization.
