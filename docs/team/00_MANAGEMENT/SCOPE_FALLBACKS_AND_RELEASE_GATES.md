# When time runs short — principled cut lines, never fake invariants

## Non-negotiable even for a demo
- Secure authentication (even fictional) / scopes; no exposed unsafe public server.
- One authoritative persisted case (not browser-only) and a route reason bound to a reviewed source.
- Invalid/skipped stage cannot mutate a case; unsigned/out-of-scope C3 correction denied.
- Only designated fictional authority records decision; no auto-approval.
- One linked obligation/evidence review distinction; one explainable reminder and canceled stale job.
- Dashboard uses authoritative data; seeded demo claims labeled.

## Safe narrower demonstration scope (approved subset if blocked)
- Two carefully reviewed 2026–27 policy fixtures only; no rule editor/advanced SHC/full appeal.
- One signed checklist, one correction round, one eligible EVC task, one conditional approval and obligation, one private document type.
- Internal in-app reminder with virtual time, no SMS/email/retry distribution infrastructure until core event dedupe works.
- One institution/one region path shown plus a negative cross-scope security test; broad analytics deferred.
- Use hand-authored fictional datasets and a narrated fallback recording if live demo or Mongo transactions unavailable. Explicitly say what is mocked or deferred.

## Blocker escalation
If Mongo replica-set transactions unavailable, do not claim atomic production writes. Team must decide either to provision disposable transaction-capable MongoDB or narrow the demo and state that transaction durability is not verified. Never silently fall back to memory.

If Member 1 API delayed, Member 2/3 continue with `fakeCorePort`/`DecisionRecorded` fixtures, export standalone domain modules and negative tests. This makes parallel work useful, but **not integrated acceptance**.

## Release check
- Source/policy review complete and reproducible fixtures.
- 401/403/409/422 security/guard tests, including C3 tampering and idempotency.
- Default test command green; TS/build pass; no critical secrets/public exposure.
- Complete golden path runnable using synthetic cases or accurately labeled prerecorded demo.
- UI screens screenshots are real and validated; no unsupported legal, SHA/WORM or official integration claims.
- README, architecture, demo guide, data-source/feature-status disclosure drafted.
