### Speaker Notes (Slide 4)
> "On Slide 4, we address the critical question every hackathon judge asks: *Is this solution legally and technically viable in the real world?*
> 
> Government systems face severe operational risks. Consider **Scope Creep**: an institution spends lakhs rectifying a building deficiency, only for a new committee to arbitrarily reject their land documents that were already cleared. NIYAMSETU solves this at the database level: cleared items generate an immutable snapshot hash. If a committee member attempts to modify an approved item, the server rejects the request with an HTTP 409 Conflict.
> 
> Consider **Statutory Authority**: Under Sections 10 and 11 of the AICTE Act, only the Council can grant approval. In NIYAMSETU, even if a user bypasses the UI and calls our PDF generation API directly, the backend checks whether an authenticated Role 5 Council decision exists. If not, it halts with an HTTP 400 Bad Request.
> 
> Furthermore, we enforce **Cross-Tenant Privacy**. An applicant from College A cannot view or tamper with College B's applications. Every state transition is recorded in our SHA-256 chained audit ledger, ensuring full evidentiary compliance under Section 65B of the Indian Evidence Act."
