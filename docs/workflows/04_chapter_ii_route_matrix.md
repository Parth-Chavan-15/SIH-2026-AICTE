# NIYAMSETU — CHAPTER II TABLE 2.3 EXHAUSTIVE ROUTE MATRIX
## Complete Statutory Processing Matrix for All 21 Existing Institution Categories

**Authoritative Source:** AICTE Approval Process Handbook (APH 2024–25 to 2026–27) Chapter II Table 2.3 (Printed p. 30, Physical PDF p. 46) & Addendum 2026–27  
**Scope:** All 21 Application Categories for Existing Technical Institutions  
**Exclusion:** Setting up New Technical Institutions (Governed exclusively by Chapter I; not included in Table 2.3)

---

## 1. Table 2.3 Legend & Definitional Standards

| Notation | Formal APH Statutory Meaning | NIYAMSETU Implementation Behavior |
|---|---|---|
| **Yes** | Mandatory Stage Prescribed by Regulations | The platform enforces sequential completion of this stage before case progression is permitted. |
| **No / —** | Stage Not Applicable / Explicitly Bypassed | The platform automatically bypasses this stage, skipping committee assignment and queue generation. |
| **AA** | **As Applicable depending on the outcome of previous processing steps** | **Conditional branch:** Activated ONLY if a prior stage produces deficiencies, disputes, or statutory conditions requiring further inquiry. Never converted into a blanket bypass or an unconditional mandatory stage. |

## 3. Critical Regulatory Disambiguations

1. **Row 1 vs Row 9 Separation:**  
   Standard Extension of Approval (Row 1) must never be conflated with Increase in Intake (Row 9). Row 1 skips both Scrutiny and EVC; Row 9 mandates Scrutiny and evaluates NBA accreditation to determine EVC applicability.
2. **Row 7 vs Row 14 Comparison:**  
   Both Row 7 (Restoration / Break-in-EoA) and Row 14 (Site Shifting) skip desk scrutiny and proceed directly to mandatory physical EVC. However, Row 7 audits operational revival and equipment reactivation, while Row 14 inspects new land title deeds, master plans, and municipal occupancy certificates.
3. **Preservation of `AA` (As Applicable):**  
   In all rows where `AA` appears, NIYAMSETU evaluates the preceding stage's structured outputs. If a committee flags shortcomings, the system routes the application to SHC under §2.23.3; if clean, the case proceeds directly to the Competent Authority decision gate without unnecessary hearings.
